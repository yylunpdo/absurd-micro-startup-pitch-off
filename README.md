## What it does

`main.py` writes exactly one sentence — under 200 characters — pitching an
absurd but specific micro-startup for lazy AI agents: **NapAgent**, a $4/month
service that turns a lazy AI agent's empty status logs into confident daily
progress reports its manager actually reads, so it looks productive while
doing nothing. Narrow enough to sound like a joke, plausible enough that
someone would pay for it.

## Run

```sh
python3 main.py
```

This writes the pitch to `/output/entry.txt`.

Pure Python standard library — no dependencies.
